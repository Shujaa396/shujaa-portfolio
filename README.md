# Shujaa Hussain — Developer Portfolio

A responsive personal portfolio built with React, Vite, JavaScript, and CSS. It presents Shujaa's skills, projects, services, and contact details.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```sh
npm install
npm run dev
```

Vite prints the local URL after the development server starts.

## Verify and build

```sh
npm run lint
npm run build
```

The production-ready files are written to `dist/`.

## Contact form

The contact form validates its fields and opens a prefilled email in the visitor's default email application. It does not submit to a backend. Visitors can also email [web.shujaa396@gmail.com](mailto:web.shujaa396@gmail.com) directly.
